# <p align="center"> SPHYNX API </p>

## Resumo
Continuação do projeto Sphynx, com foco em melhorar e acrescentar funcionalidades ao projeto original, como controle efetivo de acesso, níveis de permissão, biometria e reconhecimento facial. Sendo desenvolvido utilizando o framework Spring.

## Tecnologias
- Spring Boot
- Spring Data JPA
- Spring Validation
- Spring Security
- Token JWT
- Postgres

## Requisitos
- Possuir Postgres instalado na máquina
- Caso queira utilizar em conjunto com o frontend e um dispositivo ESP32 com o firmware do projeto, baixe nos links abaixo:
  - [Sphynx Website](https://github.com/Cliyo/sphynx-website)
  - [Sphynx-ESP32](https://github.com/Cliyo/Sphynx)
